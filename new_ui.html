sec-checker --help 3 ways: by hand, with any AI API, or via Claude Code (MCP)

manual — deterministic rules, no AI

Safest and fastest for repeatable scans. The rule-based brain decides what to run — no LLM required, no configuration needed.

A
In the web UI: type the URL, press [ run ]. You watch the flow live.
B
Or from the terminal (CLI):
python run.py auto https://TARGET --profile standard
Profiles: quick · standard · deep. Reports in reports/. When uncertain: UNKNOWN, never VULNERABLE.

ai api — any model decides what runs next

The brain (LLM) picks the next capability. Provider-agnostic: OpenAI-compatible, Anthropic, or Gemini. The key comes from an env var only — the .env file is never read.

1
Set the key as an env var (PowerShell):
$env:SECCHECKER_LLM_API_KEY = "sk-...your-key..."
2
Pick provider/model in configs/engine.yaml → brain.llm.
3
Run with the AI brain:
python run.py auto https://TARGET --brain llm --profile deep
Fail-safe: if the AI errors or is rate-limited, the run falls back to rule-based — the scan still finishes.

claude code (mcp) — Claude drives the tools

The scanners are exposed as MCP tools. You talk to Claude Code and it selects the right tools and reasons over results.

1
Register with Claude Code:
claude mcp add sec-checker -- python C:\xampp8.4\htdocs\sec-checker\sec_checker_mcp.py
2
Or run the stdio server directly:
python sec_checker_mcp.py
3
In Claude Code: "Use sec-checker to scan https://TARGET".
Same engine across all three modes — only the decision-maker differs. ROE is fail-closed everywhere.
