sec-checker black-box security scanner · local · ROE fail-closed idle

Scan a target

Enter a URL. It studies what the target is, then runs the scan live as a flow of tools.

Min severity:  ·  demo mode — pre-scripted scan, no server
How to use sec-checker — 3 ways: by hand, with any AI API, or via Claude Code (MCP)

Manual — tao ang nagpapatakbo, walang AI

Deterministic ang mga rule — walang AI na kailangan. Pinakaligtas at pinakamabilis para sa paulit-ulit na scan.

A
Sa web UI: i-type ang URL, pindutin ang Analyze & Scan. Live mong makikita ang flow sa ibaba.
B
O sa terminal (CLI):
python run.py auto https://TARGET --profile standard
Profiles: quick · standard · deep. Report sa reports/. Kapag hindi masiguro: UNKNOWN, hindi VULNERABLE.

AI API — kahit anong AI ang nagde-decide ng susunod

Ang brain (LLM) ang pumipili kung anong capability ang susunod. Provider-agnostic: OpenAI-compatible, Anthropic, o Gemini. Ang key ay galing sa environment variable lang — hindi binabasa ang .env file.

1
Ilagay ang key sa env var (PowerShell):
$env:SECCHECKER_LLM_API_KEY = "sk-...your-key..."
2
Piliin ang provider/model sa configs/engine.yaml → brain.llm.
3
Patakbuhin gamit ang AI brain:
python run.py auto https://TARGET --brain llm --profile deep
Fail-safe: kapag nag-error/na-rate-limit ang AI, babalik sa rule-based — tatapos pa rin ang scan. Ang arms pa rin ang gumagawa ng HTTP + ROE + verdict.

Claude Code (MCP) — si Claude ang gumagamit ng tools

Ina-expose ang mga scanner bilang MCP tools. Makokausap mo si Claude Code at siya na ang tatawag sa tamang tools at magre-reason.

1
I-register sa Claude Code:
claude mcp add sec-checker -- python C:\xampp8.4\htdocs\sec-checker\sec_checker_mcp.py
2
O direktang stdio server:
python sec_checker_mcp.py
3
Sa Claude Code: “Gamitin ang sec-checker para i-scan ang https://TARGET”.
Parehong engine ang tatlong mode — magkaiba lang kung sino ang nagde-desisyon. ROE fail-closed sa lahat.
